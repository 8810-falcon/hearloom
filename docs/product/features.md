# Hearloom 機能一覧

**最終更新: 2026-02-11**

## 体験フロー

```
ウィジェットタップ → アプリ起動 → 今聴いている曲が自動表示
      ↓
気分を選ぶ（必須）+ 一言（任意）
      ↓
エピソード（曲の裏話・豆知識）がAIで生成され表示（即時報酬）
      ↓
記録完了（曲・気分・時間帯・場所を収集）
      ↓
蓄積後、ふとした瞬間に通知で思い出想起
```

## Must have（MVP必須）

| 機能 | 詳細 | 優先度 |
|------|------|--------|
| **Apple Music連携** | SystemMusicPlayer.sharedで現在再生中の曲を取得 | P0 |
| **Spotify連携** | Spotify SDK (SPTAppRemote) でOAuth認証後、再生曲を取得 | P0 |
| **気分選択** | 6種類から選択（高揚/穏やか/切ない/集中/懐かし/その他） | P0 |
| **一言メモ** | 任意入力。その時の状況や思い出を記録 | P0 |
| **エピソード生成** | AIが曲の裏話・豆知識を生成して表示（即時報酬） | P0 |
| **記録保存** | 曲情報 × 気分 × 時間帯 × 場所を保存 | P0 |
| **ウィジェット** | タップでアプリ起動。記録画面を直接開く | P0 |
| **時系列履歴閲覧** | 月別、年別で過去の記録を振り返れるUI | P0 |

## Should have（価値向上）

| 機能 | 詳細 | 優先度 |
|------|------|--------|
| **セレンディピティ通知** | 「3年前の今日、この曲を聴いていました」等の通知 | P1 |
| **場所連動通知** | 特定の場所を通りかかった時に過去の記録を通知 | P1 |
| **エピソードキャッシュ** | 人気曲のエピソードを事前生成してコスト削減 | P1 |
| **記録統計** | 月間/年間の記録数、よく聴くジャンル等の可視化 | P2 |

## Could have（後回し可能）

| 機能 | 詳細 | 優先度 |
|------|------|--------|
| YouTube Music連携 | Android MediaSession経由で対応 | P3 |
| 年次レポート | Spotify Wrappedのような1年間のまとめ | P3 |
| エクスポート機能 | 記録データのJSON/CSV出力 | P3 |

## Won't have（MVPでは除外）

| 機能 | 除外理由 |
|------|----------|
| 自動収集（バックグラウンド） | 技術的制約、かつ能動的記録の方が思い出の質が高い |
| AI感情自動推定 | 記録時にユーザーが気分を選ぶ方式に変更 |
| ソーシャル機能 | MVPでは個人利用に集中 |
| 楽曲再生機能 | ライセンス問題、Apple Music/Spotifyに委譲 |

## 技術仕様

### 音楽サービス連携

| サービス | iOS | Android | 認証 |
|----------|-----|---------|------|
| Apple Music | SystemMusicPlayer.shared | - | メディアライブラリ許可 |
| Spotify | SPTAppRemote | MediaSession or SDK | OAuth認証 |

### エピソード生成

| 項目 | 仕様 |
|------|------|
| 生成方法 | **オンデバイスAI**（Apple Intelligence / Gemini Nano） |
| コスト | **0円**（端末内で完結） |
| 内容 | 曲の制作背景、アーティストの裏話、豆知識等 |
| 対応範囲 | 有名曲のみ（モデルの学習データに含まれる曲） |
| 非対応時 | 「エピソードが見つかりませんでした。代わりに一言を残しませんか？」 |

### 対応デバイス・機能差

| プラットフォーム | エピソード機能 | 記録機能 |
|-----------------|---------------|----------|
| iOS（iPhone 15 Pro以降） | ✅ 利用可能 | ✅ |
| iOS（iPhone 15 Pro未満） | ❌ 利用不可 | ✅ |
| Android（Pixel 9以降等） | ✅ 利用可能 | ✅ |
| Android（Gemini Nano非対応） | ❌ 利用不可 | ✅ |

※古いデバイスでも記録機能は利用可能（エピソード表示のみ非対応）

### データモデル

```typescript
interface Record {
  id: string;           // UUID
  songId: string;       // 曲の一意識別子
  songTitle: string;    // 曲名
  artistName: string;   // アーティスト名
  albumName?: string;   // アルバム名
  albumArtUrl?: string; // アルバムアート画像URL
  mood: MoodType;       // 気分（6種類）
  situation?: string;   // 一言メモ（任意）
  episode: string;      // AIが生成したエピソード
  location?: {          // 場所（オプトイン）
    latitude: number;
    longitude: number;
    placeName?: string;
  };
  createdAt: string;    // 記録日時（ISO 8601）
  source: 'apple_music' | 'spotify';  // 音楽サービス
}
```
