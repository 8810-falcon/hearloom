# Hearloom ユーザージャーニー

**最終更新: 2026-02-04**

## ターゲットユーザー（ペルソナ）

**名前:** 音楽ヘビーリスナー（週15時間以上）

**属性:**
- 1日2時間以上音楽を聴く
- Apple Music/Spotifyなど音楽ストリーミングサービス利用者
- 音楽を「感情コントロールツール」として意図的に使い分ける
- 音楽と自分の感情・記憶を大切にしている

**音楽聴取パターン:**
| シチュエーション | ジャンル | 目的 |
|-----------------|----------|------|
| 移動中/仕事中 | chill、ハウス、R&B | 没頭・集中 |
| 運動/プレゼン前 | EDM、アップビート | 高揚・興奮 |
| 家事中 | 多様なジャンル | リラックス・解放 |

**課題:**
- 音楽を聴いた「その瞬間」の感情が、時間とともに忘れられてしまう
- 後から振り返りたくても、いつ・どんな気持ちで聴いていたか思い出せない

**求めるもの:**
- 印象的な曲を聴いた瞬間の気持ちを簡単に残したい
- 過去の自分がどんな気持ちで音楽を聴いていたか振り返りたい
- 音楽と自分の人生のストーリーを繋げたい

## ユーザージャーニー（MVP）

### Phase 1: 導入
1. アプリをインストール
2. 簡単なオンボーディング（アプリの使い方説明）
3. 「音楽を聴いているときに、共有メニューからHearloomを選んでね」

### Phase 2: 日常利用（記録）
1. ユーザーは普段通り音楽アプリで音楽を聴く
2. 「この曲、今の気持ちと一緒に残したい」と思った瞬間に共有メニューを開く
3. Hearloomを選択 → 曲情報が自動で反映される
4. 気分を選択（必須）+ 状況を一言入力（必須）
5. 保存 → 日時とともに記録完了

### Phase 3: 振り返り（価値提供）
1. アプリを開くと、記録した曲が日付順（最新順）で一覧表示
2. 過去の記録をタップ → 当時の気分・状況が蘇る
3. 「あの時こんな気持ちで聴いてたんだ」という発見
4. 必要に応じて記録を編集

## ユーザーインタビュー結果サマリー

**実施日:** 2026-01-17
**対象:** プロジェクトオーナー（ヘビーリスナー、1日6時間聴取）

**主要な発見:**
1. 音楽を「感情コントロールツール」として意図的に使い分けている
2. 100個のプレイリストが蓄積されているが管理不能
3. 「振り返りたいが探せない」という明確な課題あり
4. 感情タグ付け機能が最も刺さる
5. 課金意欲は月額300円程度（条件付き）

**注意:** n=1のインタビューのため、追加ユーザーへのヒアリングが必要
