# Hearloom ユーザージャーニー

**最終更新: 2026-02-11**

## ターゲットユーザー（ペルソナ）

**名前:** 音楽マニア

**属性:**
- 音楽を深く楽しみたい人
- 曲の背景やアーティストのストーリーに興味がある
- 自分の音楽体験を記録・振り返りたい
- Apple Music または Spotify の有料プラン加入者

**音楽との関わり方:**
| 特徴 | 詳細 |
|------|------|
| 聴取時間 | 週15時間以上 |
| 興味 | 曲の制作背景、アーティストの裏話、音楽史 |
| 行動 | アルバムのライナーノーツを読む、インタビュー記事をチェック |
| 課題 | 聴いた曲の感動をその場で記録したい、後から振り返りたい |

**求めるもの:**
- 聴いている曲についてもっと知りたい
- 「この曲を聴いた時の気持ち」を残したい
- ふとした瞬間に過去の音楽体験を思い出したい

## ユーザージャーニー

### Phase 0: 発見・インストール

```
「音楽をもっと深く楽しみたい」
      ↓
App Storeで発見 or 友人からの紹介
      ↓
「記録するとエピソードが見れる」に興味
      ↓
インストール
```

### Phase 1: 初回セットアップ

```
アプリ起動
      ↓
「どの音楽サービスを使っていますか？」
      ↓
┌─────────────────┬─────────────────┐
│   Apple Music   │    Spotify      │
└─────────────────┴─────────────────┘
      ↓                   ↓
メディアライブラリ     Spotifyアプリで
アクセス許可          OAuth認証
（標準ダイアログ）
      ↓
ウィジェットの設置を案内
      ↓
「準備完了！音楽を聴いている時に記録してみましょう」
```

**所要時間:** 約1-2分（Apple Music）/ 約2-3分（Spotify）

### Phase 2: 初回記録体験（Aha! Moment）

```
ユーザーがApple Music/Spotifyで曲を聴いている
      ↓
ウィジェットをタップ（または通知から起動）
      ↓
Hearloomが起動、今聴いている曲が自動表示
「Official髭男dism - Pretender」
      ↓
気分を選ぶ（例: 「切ない」をタップ）
      ↓
一言メモ（任意）「帰り道、ふと聴きたくなった」
      ↓
【エピソード表示】← ここがAha! Moment
「この曲は2019年に大ヒット。実は最初はドラマ主題歌の
 オファーを断ろうとしていたが...」
      ↓
「へー！知らなかった！」
      ↓
記録完了
```

**ポイント:** 記録直後にエピソードが表示されることで「また記録したい」という動機が生まれる

### Phase 3: 日常利用（習慣化）

```
【トリガー】
- 印象に残る曲を聴いた時
- 特別な場所で音楽を聴いた時
- 懐かしい曲に出会った時

【行動】
ウィジェットタップ → 気分選択 → エピソード閲覧 → 記録

【報酬】
- 曲のエピソードを知れる（即時報酬）
- 記録が蓄積される（将来の価値）

【頻度目安】
- ヘビーユーザー: 1日1-3回
- 通常ユーザー: 週3-5回
- ライトユーザー: 週1-2回
```

### Phase 4: 蓄積価値の享受（継続利用）

```
【記録が10件を超えた頃】
アプリを開くと時系列で過去の記録が見れる
「あ、この曲聴いた時こんな気分だったんだ」

【記録が50件を超えた頃】
セレンディピティ通知が届き始める
「1年前の今日、あなたは渋谷でこの曲を聴いていました」
      ↓
通知をタップ → 記録を振り返る
「そうだ、あの日のことを思い出した」

【長期利用】
- 年次レポート: 「2025年、あなたが最も記録した気分は"高揚"でした」
- 場所連動: 特定の場所を通ると過去の記録が通知される
```

## 成功指標（KPI）

| 指標 | 目標値 | 意味 |
|------|--------|------|
| 初回記録完了率 | 70%以上 | インストール後に1件以上記録したユーザー |
| 7日後リテンション | 30%以上 | 1週間後にアプリを開いたユーザー |
| 週間記録数（アクティブユーザー） | 3件以上 | 習慣化の目安 |
| 通知タップ率 | 15%以上 | セレンディピティ通知の効果 |

## ユーザーインタビュー結果サマリー

**実施日:** 2026-01-17
**対象:** プロジェクトオーナー（音楽マニア、1日6時間聴取）

**主要な発見:**
1. 音楽を「感情コントロールツール」として意図的に使い分けている
2. 曲の背景やアーティストのストーリーに興味がある
3. 「振り返りたいが探せない」という明確な課題あり
4. 記録の「即時報酬」があれば継続できそう
5. 課金意欲は月額300円程度（エピソードの質次第）
